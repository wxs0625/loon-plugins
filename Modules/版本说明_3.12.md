# 集合修复版 v3.12 版本说明

**日期**: 2026-08-13
**SHA-256**: `0BE4AEE08B28EB8CE768A5607AC76256994EE9F5CF9EF0F888BBBCDB0A2FAFFD`

## v3.11 用户反馈的三个问题

1. 闪动校园进入软件后显示**无网络**
2. 闪动校园**开屏广告**仍然存在
3. 百度网盘**开屏广告**仍然存在

## 根本原因诊断

### 问题1：闪动校园无网络
v3.11 为了让 URL Rewrite 生效，移除了 `DOMAIN-SUFFIX,huachenjie.com,DIRECT`，导致闪动校园的国内主接口流量被路由到**海外代理节点**再经 MITM，国内应用无法正常工作 → 显示无网络。

### 问题2：闪动校园开屏广告
经查证社区规则（fmz200/wool_scripts 的 ShanDongXiaoYuan.snippet），闪动校园的**开屏广告来自第三方广告SDK**：
- 快手SDK：`open.e.kuaishou.cn/rest/e/v3/open`
- 1rtb SDK：`zlsdk.1rtb.net/sdk/req_ad`

v3.11 仅靠 URL 正则拦截，其中 1rtb 的正则要求查询参数顺序完全一致（`sdk_version`→`device_os`→`accept_ad_type`→`app_id`→`pid`→`sdk_version_code`），SDK 实际请求参数顺序变化时就会失配。

### 问题3：百度网盘开屏广告
逐条核对社区 BaiduNetdisk 16 条规则后发现：**`update.pan.baidu.com/statistics` 规则在 v3.11 中声称已补写，实际文件里并不存在**（构建脚本遗漏）。该接口是百度网盘开屏广告配置/统计来源。另外百度网盘开屏素材有本地缓存，社区也注明"需清除缓存或重新安装才会生效"。

## v3.12 修复方案

### 闪动校园（修复无网络 + 开屏广告）
| 修改 | 说明 |
|------|------|
| 恢复 `DOMAIN-SUFFIX,huachenjie.com,DIRECT` | 主接口直连国内，**修复无网络** |
| 新增 `DOMAIN,open.e.kuaishou.cn,REJECT` | 快手SDK开屏广告在规则层直接拒绝 |
| 新增 `DOMAIN,open.e.kuaishou.com,REJECT` | 快手SDK备用域名 |
| 新增 `DOMAIN,ad.shunchangzhixing.com,REJECT` | 顺昌执行（福袋广告）规则层拒绝 |
| 新增 `DOMAIN-SUFFIX,1rtb.net,REJECT` | 1rtb SDK开屏广告规则层拒绝 |

**原理**：`[Rule]` 层的域名 REJECT 在路由决策阶段就拒绝连接，**不需要流量经过代理节点、不需要 MITM 解密**，与使用哪个节点完全无关，因此可以 100% 拦截开屏广告请求。原有的 URL Rewrite 规则保留作为备份。

### 百度网盘（修复开屏广告）
| 修改 | 说明 |
|------|------|
| 补写 `update.pan.baidu.com/statistics - reject` | v3.11 漏写，本版真正写入文件 |

百度网盘 17 条社区规则已全部核对就位：pcs/ad、pcs/adx、activityentry、welfare/bchannel、guanggao、statistics、fc-video、logouts 等。

## 重要使用提示

1. **百度网盘需清缓存或重装**：社区明确说明"某些APP要清除缓存或者重新安装拦截广告才会生效"，开屏广告素材会本地缓存。
2. **闪动校园首次生效**：建议强制关闭 App 后重新打开（杀掉后台进程），开屏广告配置有内存缓存。
3. **MITM 与节点**：闪动校园的开屏广告拦截现在完全不依赖 MITM/节点；百度网盘的拦截需要 MITM 已开启且证书已信任（pan.baidu.com 已在 MITM hostname 列表中）。
