# 集合修复版版本说明

## 使用建议

- 当前推荐版本：`集合修复版_3.6.sgmodule`
- 所有中文版本都是历史文件的独立副本，没有覆盖或删除原文件。
- 文件名只使用产品名和版本号，具体功能记录在本文档中。
- `独立模块_1.0.sgmodule` 不属于集合版本线，不要与集合版同时启用相同的微博规则。

## 集合修复版 1.0

文件：`集合修复版_1.0.sgmodule`

- 将 Loon 集合修复版转换为 Shadowrocket 模块格式。
- 合并本地 33 个 Shadowrocket 模块。
- 包含广告拦截、应用净化、URL 重写、响应体处理、Map Local 和 MITM 配置。
- 初始版本中的 YouTube 响应处理可能导致联网变慢。

## 集合修复版 2.0

文件：`集合修复版_2.0.sgmodule`

- 基于 1.0。
- 加强纵横小说启动接口拦截。
- 删除 YouTube 响应脚本、Google Video `initplayback` 处理和过宽的 Google API 重写。
- 移除相关高开销 MITM，降低 YouTube 联网延迟。
- 原来的两个 v2 英文文件内容完全相同，中文版本只保留一份 2.0。

## 集合修复版 3.0

文件：`集合修复版_3.0.sgmodule`

- 基于 2.0。
- 补入之前因扩展名不同而遗漏的微博模块。
- 增加微博启动页、信息流、评论、话题、搜索、皮肤和图标等广告及净化处理。
- 保留纵横小说修复和 YouTube 低延迟调整。

## 集合修复版 3.1

文件：`集合修复版_3.1.sgmodule`

- 基于 3.0。
- 调整微博 MITM 主机顺序，提高微博相关主机的匹配优先级。
- 规则功能与 3.0 基本一致，主要变化是微博解析顺序。

## 集合修复版 3.2

文件：`集合修复版_3.2.sgmodule`

- 基于 3.0 的完整功能版本。
- 修复两个错误拼接的 MITM 主机。
- 删除已被同级通配符覆盖的精确 MITM 主机。
- 不删除广告脚本和响应体处理，在不影响完整广告拦截的前提下降低匹配开销。
- 这是保守省电版本，也是后续均衡版本的可靠基线。

## 集合修复版 3.3

文件：`集合修复版_3.3.sgmodule`

- 基于 3.2。
- 停用部分被判断为非广告的增强脚本和响应处理，以进一步降低耗电。
- 后续确认其中部分脚本同时承担广告和页面布局处理，导致部分广告拦截失效。
- **不推荐使用，仅作为历史版本保留。**

## 集合修复版 3.4

文件：`集合修复版_3.4.sgmodule`

- 修复 3.3 的广告漏拦问题。
- 恢复被误删的混合广告及布局处理。
- 只停用严格确认与广告无关的 7 条脚本和 1 条响应体处理。
- 在广告拦截完整性和耗电之间采用更保守的平衡方案。

## 集合修复版 3.5

文件：`集合修复版_3.5.sgmodule`

- 基于 3.4。
- 修复微信公众号 `getappmsgad` 同时被直接拒绝和响应体重写处理的冲突。
- 从组合拒绝规则中移除 `getappmsgad`，让微信公众号广告响应能够进入净化流程。
- 仍使用字段文本替换，部分微信版本可能出现广告素材消失但容器留白。

## 集合修复版 3.6

文件：`集合修复版_3.6.sgmodule`

- 基于 3.5，是当前推荐版本。
- 移除微信公众号旧的 `advertisement` 字段文本替换。
- 新增结构化 JSON 净化脚本，将 `advertisement_num` 设为 `0` 并清空 `advertisement_info`。
- 减少公众号正文和文章底部广告被拦截后留下空白占位的情况。
- 净化脚本保存在自己的 GitHub 仓库，避免第三方脚本变化。
- 保留微博、小红书、纵横小说及其他广告处理。
- 不恢复 YouTube 响应脚本和 Google Video 高延迟 MITM。
- 微信客户端自身固定的原生布局可能仍会保留空白区域，代理模块无法直接修改客户端界面。

## 独立模块 1.0

文件：`独立模块_1.0.sgmodule`

- 独立微博广告拦截模块。
- 包含微博启动页、信息流、评论、话题、搜索、皮肤和图标等处理。
- 适合不使用完整集合版、只需要微博处理的情况。
- 完整集合版 3.0 及之后版本已经包含对应微博能力，不应重复启用。
