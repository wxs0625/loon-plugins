# 集合修复版 3.7 说明

## 推荐版本

当前推荐：`集合修复版_3.7.sgmodule`

## 修复内容

- 基于 `集合修复版_3.6.sgmodule`。
- 修复闪动校园启用集合模块后启动异常或闪退的问题。
- 原因是快手广告 SDK 的 `open.e.kuaishou.com` 与 `open.e.kuaishou.cn` 初始化接口被硬拒绝，SDK 收到连接中断后可能导致应用异常。
- 添加闪动校园相关认证、快手 SDK 初始化和广告响应域名的优先直连。
- 删除 `e.kuaishou.com` 的冲突拒绝规则。
- 删除两个 `open/e/v3/open/univ` 硬断连重写。
- 删除同一接口的响应脚本，避免在应用初始化阶段再次修改响应。

## 保留内容

- 微信公众号结构化广告响应净化。
- 微博广告拦截与净化。
- 小红书、纵横小说及其他原有广告处理。
- YouTube 低延迟策略，不恢复高开销响应脚本和 Google Video MITM。

## 行为影响

- 闪动校园使用的快手 SDK 相关请求不再由集合模块拦截，应用可以自行完成 SDK 初始化。
- 这部分广告请求可能由应用自行决定展示与否；优先目标是保证应用稳定启动。
- 除上述快手 SDK 冲突项外，3.7 与 3.6 功能内容保持一致。

## 历史版本

完整历史版本说明见本地 `版本说明.md`。此前已发布的历史文件与订阅地址均未覆盖。
